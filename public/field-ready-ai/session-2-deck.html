Meet the Machine04

Why the transformer exists

Same words. Opposite meaning.

"I hate dogs."
"I don't hate dogs."

Nearly identical tokens — one word flips everything. Attention is the machinery that lets each word be changed by its neighbours. That's the "heart" of the model, and its most expensive part.

Meet the Machine05

The question from Session 1

Why is it confident
and wrong?

  • It picks the most probable next token. Probable is not true.
  • A fabricated citation is probability-shaped text — same machinery, no alarm bell.
  • Confidence is a property of the sampling, not of the facts.
Fluency is not knowledge.
Trust, but verify — structurally.
Meet the Machine06

Working memory

The intern has a desk.

RAM
The context window is the model's working memory — everything it can "see" right now. (Karpathy's framing: LLM = CPU, context = RAM.)
Finite
Every token attends to every other token. Attention is a budget, and every token you add competes for it.
Rot
More context is not better context. Pile on "just in case" files and quality goes down, not up.

Three files that matter beat every file in the building. Which intern does better work?

What you actually pay for

Everything. Re-sent.
Every message.

  • Everything you type · every file you attach · your project instructions · the entire conversation so far — all re-sent, every single message.
  • There is no memory. The transcript is the memory.
  • Output tokens cost ~5× input tokens.
Message 40 costs vastly more than message 1 —
it re-reads all 39 before it, for every token it writes.
